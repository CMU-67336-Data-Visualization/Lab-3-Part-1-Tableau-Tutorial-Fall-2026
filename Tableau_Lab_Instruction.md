## Tableau Lab Instruction
### Download Tableau

**Option 1** Tableau Desktop and Tableau Prep Builder

1. [Sign in](https://identity.idp.tableau.com/login) an existing [Tableau.com](https://www.tableau.com/) account, or [create] (https://id.tableau.com/register) a new account using your school-issued email
2. Once signed in, visit the [Academic Quick Start](https://www.tableau.com/tft/activation) page to download the latest versions of Tableau Desktop and Tableau Prep Builder
3. Activate with product key: `TCHJ-EEF4-D6B0-5DEE-6471`
4. Already have a copy of Tableau Desktop installed? Update the license key in the application: Help menu → Manage Product Keys

Having trouble? The [Academic Quick Start](https://www.tableau.com/tft/activation) page includes FAQs and help articles.


**Option 2** Use the free Tableau Public Desktop

1. Download the Tableau Public desktop: `https://www.tableau.com/products/public/download`

In both options, you will also need a Tableau public account. You can sign up here: `https://www.tableau.com/community/public/get-started`


### Datasets
Data for the lab can be downloaded from Western PA Regional Data Center. Download the `.csv` files for each of the following and save them to your desktop:

		Dataset 1: Public Blotter Data
		https://data.wprdc.org/dataset/uniform-crime-reporting-data
		
		Dataset 2: Pittsburgh Police Arrest Data:
		https://data.wprdc.org/dataset/arrest-data
